🏆 Local Help Request Router

«An AI-powered civic-tech solution designed to help citizens route local problems and complaints to the appropriate department or service.»

🚀 About the Project

The Local Help Request Router was developed as a working prototype during the Astrix Hackathon.

The idea is simple: citizens often face problems such as electricity issues, water supply problems, sanitation concerns, or other local service issues, but may not know which department or service they should contact.

Our system helps analyze a citizen's request, identify the relevant category and urgency, route it toward the appropriate service, and provide a way to track the complaint.

💡 Core Idea

Citizen Complaint
       ↓
AI-based Analysis
       ↓
Category & Urgency
       ↓
Department / Service Mapping
       ↓
Complaint Tracking
       ↓
Resolution

✨ Key Features

👤 Citizen Side

- Submit complaints using text input
- Support for voice-based input
- Automatic complaint categorization
- Complaint identification and tracking
- View complaint status and history
- Follow the complaint through different stages

🧑‍💼 Super Admin Dashboard

The system includes a centralized admin concept for managing the complaint-routing system.

- Dashboard overview
- Category management
- Service-to-department mapping
- Complaint management
- Location-based mapping
- Urgency rule configuration
- Complaint status management

🔄 Complaint Tracking

Each complaint can have a unique ID and a structured status flow:

Submitted
    ↓
Assigned
    ↓
In Progress
    ↓
Resolved

This tracking approach is intended to improve transparency and user trust by allowing citizens to understand what is happening with their complaint.

🔐 Role-Based Access

The project was designed around two main roles:

👤 User / Citizen

- Submit complaints
- View generated complaints
- Track complaint status
- View personal complaint history

🧑‍💼 Admin / Super Admin

- Access the admin dashboard
- Manage categories
- Configure service mappings
- View complaints
- Update complaint status
- Configure urgency rules

The architecture can be extended in the future to support department-level administrators.
